# Sarai Group visual system

Corporate digital transformation website with a structured editorial layout.

## Color

- Primary blue: `#0D0D95` for the hero, navigation actions, and headings.
- Purple: `#661D77` for emphasis, markers, and supporting surfaces.
- White and pale lavender: spacious reading backgrounds.

## Typography

Segoe UI Variable / Segoe UI with a restrained scale, strong section headings, and compact uppercase metadata. The serif letterform in the hero diagram is a visual mark only.

## Layout and components

The homepage moves from a strong brand statement to capabilities, a lifecycle rail, project stories, and a company directory. Main content stays inside a 1320px shell. Case studies use a three-column grid at desktop and single column on phones. Company links use a list with clear separators.

## Accessibility

Links and buttons use visible focus outlines. Motion respects reduced-motion preferences. The page has semantic headings and landmark navigation.
